Learning Center

Learn the parameters and understand how the transformation is built.

1. Link length · aᵢ₋₁

Translation along the previous frame's X axis. It represents the common-normal distance between adjacent joint axes.

2. Link twist · αᵢ₋₁

Rotation about the previous frame's X axis, describing the angle between the adjacent Z axes.

3. Joint angle · θᵢ

Rotation about the current joint Z axis. It is variable for revolute joints.

4. Joint offset · dᵢ

Translation along the current joint Z axis. It is variable for prismatic joints.

Your chosen transformation order

T = Rx(αᵢ₋₁) Tx(aᵢ₋₁) Rz(θᵢ) Tz(dᵢ)

The first two operations commute because both act along/about X. The row indexing and frame assignment still matter.

How to check your answer

1. Validate every frame assignment. 2. Build each 4×4 matrix. 3. Multiply left-to-right. 4. Read the final matrix's last column for position. 5. Check units and joint-axis signs.
